# Portal Libs Guide

Portal frontend libs는 `src/portal/{package}/libs`에 둔다. TypeScript helper, vendor script, component utility를 package와 함께 배포할 때 사용한다.

원칙:

- npm으로 관리 가능한 의존성은 `src/angular/package.json`에 둔다.
- package에 묶여야 하는 고정 vendor file만 `libs/`에 둔다.
- 대형 vendor 파일을 갱신할 때는 출처와 버전을 README나 vendor manifest에 남긴다.
- backend Java dependency와 frontend libs를 혼동하지 않는다. Java dependency는 workspace `pom.xml`에 둔다.
