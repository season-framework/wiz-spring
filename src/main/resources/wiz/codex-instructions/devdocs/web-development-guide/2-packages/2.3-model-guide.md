# Portal Model Guide

Portal model은 package domain의 재사용 계층이다.

```text
src/portal/post/model/
  PostStruct.java
  db/PostEntity.java
  struct/PostService.java
```

package 선언이 없으면 build 산출물에서 `{packageRoot}.module.{package}.application.model...`, `{packageRoot}.module.{package}.application.service...`, `{packageRoot}.module.{package}.domain.entity...` 같은 Spring 계층형 package로 rewrite된다.


```java
import com.wiz.runtime.WizContext;

public final class Struct {
    private final UserStruct user;

    public Struct(WizContext wiz) {
        this.user = new UserStruct(wiz);
    }

    public static void warmup(WizContext wiz) {
        new Struct(wiz);
    }

    public UserStruct user() {
        return user;
    }
}
```


Root `Struct`에서 portal struct를 조합하면 App API는 하나의 진입점으로 domain을 사용할 수 있다.
