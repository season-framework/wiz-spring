# Portal App Guide

Portal app은 `src/portal/{package}/app/{id}`에 둔다.

```text
src/portal/post/app/list/
  app.json
  view.pug
  view.ts
  view.scss
  api.java
```

Portal app API도 `/wiz/api/portal.{package}.{app}/{function}` 패턴으로 dispatch된다. sample의 `portal.post.list`와 `portal.post.detail`을 기준으로 작성한다.

`mode`는 일반 page보다 `portal` 또는 component 성격에 맞게 둔다. template selector는 `wiz-portal-{package}-{app}()` 형태를 권장한다.
