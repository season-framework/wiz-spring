# App Guide

App은 화면, metadata, app-local backend를 한 디렉터리에 둔다.

```text
src/app/page.members/
  app.json
  view.pug
  view.ts
  view.scss
  api.java
```

## app.json

```json
{
  "mode": "page",
  "id": "page.members",
  "title": "/members",
  "namespace": "members",
  "viewuri": "/members",
  "controller": "user",
  "layout": "layout.sidebar",
  "template": "wiz-page-members()"
}
```

`controller`는 요청 전처리 chain이다. `user`와 `admin`은 core 기본 guard와 app override를 함께 사용한다.

## api.java


```java
import com.wiz.runtime.WizContext;
import com.wiz.runtime.WizResult;

public final class PageExampleApi {
    public record StatusResponse(String text) {}

    public WizResult status(WizContext wiz) {
        String text = wiz.request().query("text", "hello");
        return wiz.response().status(200, new StatusResponse(text));
    }
}
```

응답 구조가 고정되어 있으면 record/class DTO를 기본으로 사용한다. key가 동적으로 바뀌는 설정, 검색 조건, 임시 metadata처럼 자유 형식 payload가 필요한 경우에만 `Map`을 사용한다.


## Frontend call

```ts
const result = await this.wiz.call("status", { text: "hello" });
```

`wiz.call()`은 기본적으로 JSON body를 POST로 보낸다. file upload는 `FormData`를 그대로 전달한다.
