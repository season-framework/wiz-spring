# Assets Guide

정적 자산은 app source 아래에 둔다.

```text
src/assets/
src/portal/{package}/assets/
src/portal/{package}/libs/
```

Build 후 `bundle/www`로 복사되거나 Angular build에 포함된다. source asset만 수정하고 bundle 산출물은 수정하지 않는다.

파일 다운로드나 private asset access가 필요하면 workspace root 기준 안전 경로를 계산하고 `wiz.response().download(path, filename)`으로 반환한다.
