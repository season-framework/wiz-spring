# Angular Guide

WIZ Spring sample은 Angular 21과 TypeScript 5.9 계열을 기준으로 한다.

## 위치

```text
src/angular/
  angular.json
  package.json
  app/
  styles/
  wiz.ts
```

## Build

`src/angular/package.json`이 있으면 `wiz-spring build`가 Angular CLI를 실행한다. lockfile이 있으면 `npm ci`, 없으면 `npm install` 후 `ng build`를 수행한다. Angular build가 불가능하거나 입력이 없으면 최소 fallback bundle을 생성한다.

## WIZ frontend helper

```ts
const wiz = new Wiz().app("page.dashboard");
const result = await wiz.call("overview", {});
const socket = wiz.socket();
```

`wiz.call()`은 기본적으로 `/wiz/api/{namespace}/{function}`으로 요청한다. `wiz.socket()`은 native WebSocket endpoint `wiz.socket.path/{namespace}`를 사용하며 기본값은 `/wiz/app/{namespace}`다. `/socket.io/` Socket.IO polling 호환 namespace도 같은 `wiz.socket.path/{namespace}`를 사용한다.

## 작성 원칙

- App component는 `view.ts` class와 `view.pug` template을 함께 관리한다.
- 대형 전역 의존성은 `src/angular/package.json`에 추가한 뒤 clean build로 확인한다.
- generated Angular output은 `bundle/www`에 생성되며 직접 수정하지 않는다.
