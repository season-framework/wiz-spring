# Routing Guide

## Page routing

`app.json.viewuri`가 page URL을 결정한다.

```json
{
  "id": "page.dashboard",
  "mode": "page",
  "viewuri": "/dashboard",
  "layout": "layout.sidebar"
}
```

Spring runtime은 `bundle/www` 정적 파일과 SPA fallback을 제공한다. App API는 page routing과 분리되어 `/wiz/api/{app_id}/{function}`으로 호출한다.

WIZ Spring은 하나의 workspace에 하나의 app source만 사용한다. 여러 app bundle을 전환하는 project selection cookie는 없다.
