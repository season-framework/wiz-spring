# Controller Guide

Controller는 App API와 Route 실행 전 공통 정책을 적용한다.

## 위치

```text
src/controller/
  BaseController.java
  UserController.java
  AdminController.java
```

## 구현


```java
import com.wiz.dispatch.ControllerHook;
import com.wiz.runtime.WizContext;
import com.wiz.runtime.WizResult;

public final class UserController implements ControllerHook {
    @Override
    public WizResult before(WizContext wiz) {
        wiz.response().data("session", wiz.session().toMap());
        return wiz.auth().requireUser(wiz);
    }
}
```


`before()`가 `null`을 반환하면 다음 단계가 실행된다. `WizResult`를 반환하면 chain이 중단되고 해당 응답이 반환된다.

## Built-in names

| 이름 | 의미 |
| --- | --- |
| `base` | session data를 response data bag에 노출 |
| `user` | `id` session 필수 |
| `admin` | `role=admin` session 필수 |

workspace source에 같은 이름의 controller class가 있으면 app 구현을 우선 사용할 수 있다.
