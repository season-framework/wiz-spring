# WIZ Spring Devdocs

이 디렉터리는 WIZ Spring 기준 개발 문서다.

- `instructions/`: 작업 원칙, 빠른 API 참조, 테스트 방법
- `web-development-guide/`: source 및 portal package 작성법
- `wiz-docs/`: 런타임 API와 CLI 문서
- `feature-guide/`: 인증/세션, startup warmup 같은 기능 설계
- `troubleshooting/`: Spring 런타임 문제 해결

기준 구현은 `/root/workspace/wiz-java/wiz-spring`이며, sample source는 `wiz-spring/src/main/resources/wiz/templates/default-project-java`에 있다.
