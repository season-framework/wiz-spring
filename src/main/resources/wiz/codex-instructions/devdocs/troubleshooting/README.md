# Troubleshooting

Spring 기준 문제 해결 문서다. `server-side/python-runtime`이라는 디렉터리 이름은 기존 문서 구조 호환을 위해 남아 있지만, 본문은 Java/Spring runtime 이슈를 다룬다.

- `server-side/api/`: API request/response/routing
- `server-side/build/`: build와 bundle reload
- `server-side/config/`: YAML 설정
- `server-side/python-runtime/`: Java runtime/class loading 이슈
- `web-ui/`: Angular, Pug, CSS 이슈
