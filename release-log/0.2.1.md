# WIZ Spring 0.2.1

릴리즈 날짜: 2026-07-08

WIZ Spring `0.2.1`은 workspace root 해석을 CLI 전반에서 일관되게 처리하고, 잘못된 root 입력을 더 명확하게 거부하도록 정리한 패치 릴리즈입니다.

## 주요 변경

- `WorkspaceRootResolver`를 추가해 `build`, `bundle`, `run`, `service install`, `codex`, `mcp`의 workspace root 탐지를 공통화했습니다.
- `--root`가 workspace 하위 디렉터리를 가리켜도 상위 WIZ Spring workspace root를 자동 탐지하도록 정리했습니다.
- `mcp`는 `--root`가 없을 때 `WIZ_WORKSPACE` 환경 변수를 우선 사용할 수 있게 했습니다.
- workspace가 아닌 경로를 넘기면 `WIZ Spring workspace root not found` 메시지와 함께 실패하도록 테스트를 보강했습니다.
- `run --dry-run` 출력이 picocli output writer를 사용하도록 바꿔 테스트와 호출자 capture가 안정적으로 동작합니다.
- `config/wiz.yaml`도 workspace marker로 인식하도록 `PathService`를 확장했습니다.
- `WizSpringApplication.runServer(String, String, int, boolean, String)` 오버로드가 자기 자신을 재귀 호출하던 문제를 수정했습니다.

## 업그레이드 안내

- Runtime artifact는 `target/wiz-spring-0.2.1.jar`입니다.
- CLI에서 `--root`를 생략하거나 workspace 하위 경로를 넘기는 경우에도 workspace root 자동 탐지를 사용합니다.
- 자동 탐지가 실패하는 환경에서는 명시적으로 workspace root를 `--root <path>`로 전달하거나, MCP 실행 시 `WIZ_WORKSPACE`를 설정하세요.
