# WIZ Spring 0.0.7

릴리즈 날짜: 2026-07-03

WIZ Spring `0.0.7`은 서버 시작 직후 기본 project runtime을 미리 준비할 수 있도록 warmup hook을 추가한 릴리즈입니다. 기본 Java sample project는 이 hook으로 JPA/Hikari pool, SQLite 파일, seed data를 먼저 초기화해 첫 로그인 요청의 지연을 줄입니다.

## 주요 변경

- `wiz.project.warmup-enabled` 설정을 추가했습니다. 기본값은 `true`이며 서버 기동 시 기본 project warmup을 수행합니다.
- `ProjectWarmupService`를 추가해 기본 project의 `model.Struct.warmup(WizContext)` static hook을 선택적으로 호출합니다.
- Warmup 실패는 서버 시작을 막지 않고 경고 로그로 남기도록 처리했습니다.
- 기본 Java sample project의 `Struct.warmup(WizContext)` hook을 추가해 기존 seed 초기화 흐름을 서버 시작 단계에서도 실행할 수 있게 했습니다.
- 기본 sample project 설정과 README에 warmup 옵션, 첫 로그인 지연 감소 효과, 외부 DB 환경에서의 비활성화 방법을 문서화했습니다.
- Java sample project 테스트가 warmup 이후 SQLite DB 파일 생성과 로그인 흐름을 함께 검증하도록 보강했습니다.

## 업그레이드 안내

- Runtime artifact는 `target/wiz-spring-0.0.7.jar`입니다.
- 기존 project는 `model.Struct.warmup(WizContext)` hook이 없으면 warmup을 건너뛰며 기존 동작을 유지합니다.
- 외부 DB가 서버보다 늦게 뜨거나 기동 시점 DB 연결을 피해야 하는 환경에서는 project 또는 workspace `application.yml`에서 `wiz.project.warmup-enabled: false`로 설정하세요.
- 이미 실행 중인 `wiz-spring run` 프로세스는 새 runtime을 사용하도록 재시작해야 합니다.
