# 0.0.1

상태: tagged

Python WIZ `2.5.2` 기준 Spring Boot 포팅의 첫 태그다.

## 포함 내용

- Spring Boot runtime/CLI 골격 추가
- `wiz create`, `wiz project create/build/list/delete/export`, `wiz run` 기본 흐름 추가
- app-local `api.java`, `route.java`, `socket.java` compile/dispatch 기반 추가
- static/SPA fallback, HTTP envelope, session/auth/config facade 추가
- SQLite sample ORM/model helper, portal season 일부 모델, PWA/SMTP boundary 추가
- 표준 JSON WebSocket endpoint(`/wiz/ws/app/{project}/{app_id}`) 추가
- Angular/Pug source staging, Java sample build/run smoke test 기반 추가

## 비고

- 이 태그 시점의 기본 Java sample project는 jar 내부 리소스가 아니라 외부 `wiz-sample-project-java` 디렉토리 탐색에 의존했다.
- `wiz server` 호환 CLI는 Spring port 범위에서 제외한다.
