# WIZ Spring 0.1.0

릴리즈 날짜: 2026-07-06

WIZ Spring `0.1.0`은 project/app 런타임 경계를 정리하고, 기본 실시간 통신과 관측성, Angular 21 템플릿 검증 흐름을 보강한 릴리즈입니다. `0.0.x` 포팅 릴리즈를 지나 CLI와 runtime 사용 단위를 app 중심으로 단순화했습니다.

## 주요 변경

- `project` 하위 명령을 `create`, `build`, `jar` 최상위 명령으로 정리하고 app 생성/빌드 흐름에 맞춰 CLI 도움말과 테스트를 갱신했습니다.
- Project 생성 흐름을 app package root 기반으로 리팩터링하고 기본 scaffold의 Java package, config, dependency 위치를 정리했습니다.
- 기본 `wiz.socket()` 전송을 Socket.IO client 의존성 없는 native WebSocket으로 전환하고, Socket.IO HTTP polling은 호환 경로로 유지했습니다.
- Socket 연결 시 Servlet `HttpSession`, cookie snapshot, remote address를 연결하고 socket handler dispatch 전에 controller 권한 정책을 적용하도록 보강했습니다.
- Runtime cache hit 시 build marker를 우선 사용하고 dispatch 내부의 중복 runtime 조회를 줄였습니다.
- Project config loading을 `ProjectConfigLoader`로 분리하고 runtime cache 생명주기에 맞춘 config cache를 정리했습니다.
- `wiz.observability()`와 project runtime health indicator를 추가해 project-local health, gauge, timer/transaction metric 등록을 지원합니다.
- 기본 sample JPA runtime이 Hikari pool gauge, JPA health, transaction duration metric을 등록하고 runtime close 시 함께 해제하도록 개선했습니다.
- Angular 21 기본 템플릿을 `platformBrowser()` bootstrap 기준으로 정리하고, 불필요한 Karma/Jasmine/keyboard shortcut 의존성과 sortablejs spec 산출물을 제거했습니다.
- `scripts/verify-angular-platform-browser.mjs`를 추가해 임시 workspace에서 render, `@Input`, `@Output`, routerLink 동작을 실제 브라우저로 검증할 수 있게 했습니다.
- README와 Angular 21 upgrade 문서에 새 검증 스크립트와 bootstrap 기준을 반영했습니다.

## 업그레이드 안내

- Runtime artifact는 `target/wiz-spring-0.1.0.jar`입니다.
- 기존 `wiz-spring project create/build/jar` 호출은 새 최상위 `wiz-spring create/build/jar` 흐름으로 교체하세요.
- Socket.IO client를 직접 쓰던 project는 호환 polling endpoint를 계속 사용할 수 있지만, 기본 template의 `wiz.socket()`은 native WebSocket을 사용합니다.
- Source/config/pom 변경 후에는 bundle build로 marker를 갱신해야 runtime cache와 config cache가 새 값을 읽습니다.
- Angular sample의 browser-level smoke가 필요하면 `node scripts/verify-angular-platform-browser.mjs`를 실행하세요.
