# WIZ Spring 0.2.2

릴리즈 날짜: 2026-07-08

WIZ Spring `0.2.2`는 systemd 서비스 제거 흐름을 보강한 패치 릴리즈입니다. `service uninstall` 계열 명령이 서비스 파일만 삭제하지 않고, 실행 중인 서비스를 먼저 중지한 뒤 disable, 파일 삭제, daemon reload를 수행하도록 정리했습니다.

## 주요 변경

- `wiz-spring service uninstall/remove/delete/rm/unregister` 실행 시 `systemctl stop <service>`를 먼저 호출하도록 수정했습니다.
- Uninstall 순서를 `stop` → `disable` → command/unit 파일 삭제 → `daemon-reload`로 명확히 정리했습니다.
- 테스트에서 실제 systemd 대신 fake `systemctl`을 주입할 수 있도록 uninstall 경로에 hidden `--systemctl` 옵션을 추가했습니다.
- `WizCommandTest`에 uninstall 실행 순서, 파일 삭제, daemon reload 호출을 검증하는 테스트를 추가했습니다.

## 업그레이드 안내

- Runtime artifact는 `target/wiz-spring-0.2.2.jar`입니다.
- 기존 서비스 제거 시에는 새 runtime으로 `wiz-spring service uninstall <name>`을 실행하면 running service stop과 daemon reload까지 함께 처리됩니다.
