# WIZ Spring 0.2.3

릴리즈 날짜: 2026-07-15

WIZ Spring `0.2.3`은 Java/Spring 개발환경을 재현 가능한 Docker 이미지로 제공하고, 초기 build의 Java package 선택과 새 sample workspace의 devlog 초기화 동작을 정리한 패치 릴리즈입니다.

## 주요 변경

- Java 21 JDK, Maven 3.9, Node.js 22, Codex CLI, SSH와 기본 개발 도구가 포함된 runtime 및 bind Docker image를 추가했습니다.
- `wiz-spring-instruction`을 image의 `/opt/app/.github`에 포함하고, bind image의 최초 workspace seed에도 동일하게 반영했습니다.
- `wiz-spring build --package <package>`로 첫 성공 bundle build 전에 Java package root를 변경할 수 있게 했습니다. 설정, Maven groupId와 source package 참조가 함께 변경되며 clean build가 자동 적용됩니다.
- `create`와 `build`에서 중복 별칭이었던 `--package-root`를 제거하고 `--package`만 사용하도록 CLI를 단순화했습니다.
- 기본 sample workspace는 빈 `devlog/`와 표 header만 있는 `devlog.md`로 생성합니다.
- `create --path`와 `create --uri`로 가져온 source의 기존 devlog 이력은 그대로 보존합니다.
- `wiz-track-apt` 관련 구성은 포함하지 않았습니다.

## 업그레이드 안내

- Runtime artifact는 `target/wiz-spring-0.2.3.jar`입니다.
- 새 package를 초기 build에서 선택하려면 `create --package <temporary-package> --skip-build` 후 `build --package <final-package>`를 실행합니다.
- `--package-root`를 사용하던 script는 `--package`로 변경해야 합니다.
- Docker image tag는 runtime `registry.nanoha.kr/kwon3286/wiz-spring:0.2.3`, bind `registry.nanoha.kr/kwon3286/wiz-spring:0.2.3-bind`입니다.

## 검증

- `./mvnw test`
- `./mvnw -DskipTests package`
- `java -jar target/wiz-spring-0.2.3.jar --version`
- `docker build --check --build-context wiz-spring-instruction=../wiz-spring-instruction --target runtime .`
- runtime/bind image build 및 container health/content 확인
- `git diff --check`
