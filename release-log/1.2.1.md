# WIZ Spring 1.2.1

상태: released (`1.2.1` 태그, 2026-09-10)

WIZ Spring `1.2.1`은 프로젝트 생성과 직접 관계없는 Node.js/npm 사전 검사가
호환 가능한 개발 환경까지 차단하던 문제를 수정한 패치 릴리스입니다.

## 프로젝트 생성

- `create`에서 Node.js/npm이 없거나, 버전 명령이 실패·중단·timeout되거나, 인식할 수
  없는 버전을 반환해도 프로젝트 생성을 중단하지 않습니다.
- 범위를 벗어난 버전과 prerelease도 생성 실패 대신 `Toolchain warning`으로 안내합니다.
- 프로젝트 생성 전에 반드시 충족해야 하는 toolchain 조건은 `javac`가 포함된 full
  JDK 25 이상으로 한정했습니다.
- Node.js/npm을 사용할 수 없는 `PATH`에서 실제 generator JAR로 프로젝트와 `.env`가
  정상 생성되는 것을 확인했습니다.

## 프론트엔드 toolchain 정책

- Node.js 범위를 `^22.22.3 || ^24.15.0 || >=26.0.0`으로 확장해 고정된 Angular
  CLI/build 패키지의 실제 지원 범위와 맞췄습니다.
- npm 최소 버전을 10에서 8로 완화해 고정된 프론트엔드 도구의 지원 범위와 맞췄습니다.
- 다섯 템플릿의 `package.json`, lockfile, README, AI 인스트럭션과 독립
  `wiz-spring-instruction` 저장소를 같은 정책으로 동기화했습니다.

## 유지되는 1.2 계약

- 기본 systemd 서비스는 `npm run dev`를 직접 실행하는 실시간 개발 모드입니다.
- 설치된 서비스와 생성 프로젝트는 WIZ Spring CLI에 런타임 의존하지 않습니다.
- 프로젝트와 bundle은 복사 단계 없는 `.env`를 제공하며, production bundle은 JDK
  25 이상만 있는 서버에서 `./run.sh`로 실행할 수 있습니다.
- 사용하지 않는 `completion` 명령은 계속 제외됩니다.

## 검증

- Generator Maven test 95개 통과
- Node.js/npm이 없는 환경에서 실제 `create` 성공 및 경고 출력 확인
- 다섯 템플릿 fresh create 후 `npm ci`, audit, frontend/backend test, build, bundle,
  checksum 검증 통과
- npm install 과정에서 `EBADENGINE`을 포함한 dependency 경고가 없음을 확인
- Generator 및 독립 instruction 저장소의 문서 정책 검증 통과
