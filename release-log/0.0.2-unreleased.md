# 0.0.2-unreleased

상태: unreleased

현재 작업 브랜치에서 진행한 CLI parity, 문서, 기본 sample packaging 보강 릴리즈 후보 기록이다.

## CLI

- `wiz bundle` 추가: build된 project bundle을 deploy/runtime bundle directory로 생성
- `wiz kill` 추가: Spring WIZ `run` process marker만 대상으로 종료하며 `--dry-run` 지원
- `wiz service list/regist/unregist/status/start/stop/restart` 추가: Linux/systemd 서비스 등록 및 제어
- `wiz run --bundle --log` compatibility option 추가
- `wiz project app list/create/delete` 추가
- `wiz project controller list/create/delete` 추가
- `wiz project route list/create/delete` 추가
- `wiz project package list/create/delete` 추가
- `wiz project npm list/install/uninstall` 추가

## Build And Runtime

- `project create` 기본 동작을 clean bundle build까지 수행하도록 유지하고, `--skip-build`로 scaffold/import만 가능하게 정리
- Java version, npm install, Pug compile, Angular build 로그와 단계별/총 소요 시간 출력 유지
- 기본 HTTP 포트를 기존 WIZ 흐름에 맞춰 `3000`으로 통일
- `wiz run`이 workspace `config/application.yml`과 project `config/application.yml`을 Spring Boot 설정으로 로드하도록 정리
- project별 `pom.xml`을 지원하고, `wiz project build` 중 `mvn dependency:copy-dependencies`로 `target/dependency` jar를 Java compile/runtime classpath에 포함
- project-local `lib/*.jar`와 bundle `lib/*.jar`를 project Java API/model/controller/socket classloader에 포함
- project-local `src/auth/AuthService.java`, `src/session/SessionService.java` convention과 `application.yml` class override로 auth/session 구현체를 project별로 교체 가능하게 추가
- 기본 sample project의 `/auth/check`는 인증 실패도 HTTP 200 + body status false 계열로 응답하도록 기존 WIZ 동작에 맞춤
- JSON body가 `wiz.request().query(...)` 경로에서 비어 보이던 문제를 기존 request parsing 정책에 맞춰 보정
- `socket.java` 변경 후 `project build`가 끝나면 서버 재시작 없이 다음 WebSocket dispatch에서 새 handler를 읽는 동작을 테스트로 고정
- core에 있던 `PageXyzSocketController` 예제 구현을 제거하고 test fixture/project build 산출물 경계로 이동

## Project Template

- 외부 `wiz-sample-project-java` 디렉토리 의존을 제거하고, 기본 Java sample project를 jar 내부 resource로 내장
- `project create --uri/--path`가 없는 경우 내장 sample을 기본으로 사용
- 내장 sample resource를 zip 대신 `src/main/resources/wiz/templates/default-project-java/` 디렉터리와 manifest 파일로 관리해 git diff에서 변경 내용을 확인 가능하게 변경
- 내장 sample은 `test1/project/main`의 source/config/data를 기준으로 하며 generated artifact(`build`, `bundle`, `.wiz`, `node_modules`)는 제외
- SQLite sample ORM helper를 core `com.wiz.persistence`에서 제거하고 내장 sample project의 `src/portal/season/model/orm`으로 이동
- sample의 SQLite JDBC와 password crypto dependency를 `wiz-spring/pom.xml`이 아니라 sample `pom.xml`에 선언
- PWA `/sw.js` 처리를 core controller가 아니라 sample project route source로 이동
- `/auth/check`, `/auth/logout`, OIDC/SAML placeholder route 처리를 core route bean이 아니라 sample project route source로 이동

## Core Boundary

- WIZ Spring core에서 portal package backend provider(`PWA`, `SMTP`, `SeasonConfig` model provider, session model provider)를 제거
- core `WizContext`에서 sample 전용 `wiz.orm()` 진입점을 제거하고, project-local model/helper를 `wiz.models()` convention으로 로드하도록 경계를 정리
- `wiz-spring/pom.xml`에서 sample 전용 SQLite/Spring Security Crypto dependency를 제거
- Python project migration/stub 생성 코드와 `project create --java-stubs` option 제거

## Documentation

- Java/Spring 의존성 설치 기준을 runtime `pom.xml`, project `pom.xml`, project-local `src/angular/package.json`로 분리해 문서화
