# 0.0.2-unreleased

상태: unreleased

현재 작업 브랜치에서 진행한 CLI parity, 문서, 기본 sample packaging 보강 릴리즈 후보 기록이다.

## CLI

- `wiz bundle` 추가: build된 project bundle을 deploy/runtime bundle directory로 생성
- `wiz kill` 추가: Spring WIZ `run` process marker만 대상으로 종료하며 `--dry-run` 지원
- `wiz service list/regist/unregist/status/start/stop/restart` 추가: Linux/systemd 서비스 등록 및 제어
- `wiz run --bundle --log` compatibility option 추가
- `wiz project app list/create/delete` 추가
- `wiz project controller list/create/delete` 추가
- `wiz project route list/create/delete` 추가
- `wiz project package list/create/delete` 추가
- `wiz project npm list/install/uninstall` 추가

## Build And Runtime

- `project create` 기본 동작을 clean bundle build까지 수행하도록 유지하고, `--skip-build`로 scaffold/import만 가능하게 정리
- Java version, npm install, Pug compile, Angular build 로그와 단계별/총 소요 시간 출력 유지
- `/auth/check`는 인증 실패도 HTTP 200 + body status false 계열로 응답하도록 기존 WIZ 동작에 맞춤
- JSON body가 `wiz.request().query(...)` 경로에서 비어 보이던 문제를 기존 request parsing 정책에 맞춰 보정
- `socket.java` 변경 후 `project build`가 끝나면 서버 재시작 없이 다음 WebSocket dispatch에서 새 handler를 읽는 동작을 테스트로 고정

## Project Template

- 외부 `wiz-sample-project-java` 디렉토리 의존을 제거하고, 기본 Java sample project를 jar 내부 resource로 내장
- `project create --uri/--path`가 없는 경우 내장 sample을 기본으로 사용
- 내장 sample은 `test1/project/main`의 source/config/data를 기준으로 하며 generated artifact(`build`, `bundle`, `.wiz`, `node_modules`)는 제외

## Documentation

- `README.md`를 한국어 중심으로 정리하고 영문 quick reference 유지
- Java/Spring 의존성 설치 기준을 Maven `pom.xml`과 project-local `src/angular/package.json`로 분리해 문서화
- `wiz-copilot-instructions`의 핵심 지시를 Java Spring port 기준으로 갱신
- Angular build 설명을 `ngc-esbuild` 같은 별도 custom pipeline이 아니라 Angular CLI 내장 esbuild builder 기준으로 정리
