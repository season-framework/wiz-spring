# WIZ Spring 0.0.6

릴리즈 날짜: 2026-07-02

WIZ Spring `0.0.6`은 `wiz-spring run`으로 서버를 띄운 상태에서 project Java API 변경과 로그 확인이 더 예측 가능하게 동작하도록 정리한 릴리즈입니다. normal build의 frontend install 비용도 줄여, 반복 빌드 시 `npm install`을 다시 수행하지 않도록 했습니다.

## 주요 변경

- normal `project build`에서 `build/src`와 generated Java source의 stale 입력을 제거하되 `build/src/angular/node_modules`는 보존하도록 변경했습니다.
- `--clean` build에서만 `npm ci` 또는 `npm install`을 실행합니다. normal build는 npm install을 건너뛰고 기존 `node_modules`로 Pug/Angular build를 수행합니다.
- normal build에서 frontend dependency가 없으면 npm install을 자동 실행하지 않고 `--clean` build가 필요하다는 메시지로 실패합니다.
- app-local Java API/socket source가 기존 `api.java`, `socket.java`뿐 아니라 handler class 이름 파일(`PageAccessApi.java`, `PageChatSocketController.java` 등)이어도 컴파일 대상으로 인식합니다.
- stale generated Java source를 제거해 `api.java` 삭제/이름 변경 후에도 이전 class가 계속 실행되는 문제를 막았습니다.
- `app.json` normalizer가 handler 이름 Java source도 API/socket handler metadata로 기록합니다.
- `wiz-spring run --log <file>`이 서버 stdout/stderr를 지정 파일에 tee 하도록 변경해 project API의 `System.out.println` 출력도 로그 파일에서 확인할 수 있습니다.
- README의 artifact 경로, build/npm install 정책, app-local Java source 규칙, run log 설명을 `0.0.6` 기준으로 갱신했습니다.

## 업그레이드 안내

- Runtime artifact는 `target/wiz-spring-0.0.6.jar`입니다.
- 이미 실행 중인 `wiz-spring run` 프로세스는 새 runtime을 사용하도록 재시작해야 합니다.
- frontend dependency를 처음 설치하거나 `package.json`/lockfile을 변경한 경우에는 `wiz-spring project build --clean`을 실행하세요. 이후 normal build는 `node_modules`를 재사용합니다.
- app-local API는 기존 `api.java`를 계속 사용할 수 있습니다. class 이름 파일로 관리하려면 기본 handler 이름(`PageAccessApi.java`) 또는 `app.json.api.handler`의 simple class name과 일치시키세요.

## 검증

- `./mvnw test`
- `./mvnw -DskipTests package`
- `java -jar target/wiz-spring-0.0.6.jar project build --root ../demo --project main`
- `java -jar target/wiz-spring-0.0.6.jar run --root ../demo --project main --host 127.0.0.1 --port 18080 --log /tmp/wiz-run-test.log`
- `/wiz/api/page.access/login`의 수정된 Java 응답과 `/tmp/wiz-run-test.log`의 `System.out.println` 출력 확인
