# WIZ Spring 1.2.2

상태: released (`1.2.2` 태그, 2026-09-11)

WIZ Spring `1.2.2`는 생성 프로젝트의 production bundle을 실제 배포에 필요한 네
항목으로 줄이고, reverse proxy의 lifecycle을 애플리케이션 Compose와 분리한 패치
릴리스입니다.

## 최소 배포 bundle

- `npm run bundle`은 root `application.jar`(JSP는 `application.war`), `public/`,
  `.env`, `docker-compose.yaml`만 원자적으로 게시합니다.
- 기존 `app/`, `config/`, `data/`, `deploy/`, `run.sh`, `manifest.json`,
  `SHA256SUMS` 생성 단계를 제거했습니다.
- JDK 25 이상이 있는 서버에서는 bundle `.env`를 읽고 root archive를 `java -jar`로
  직접 실행할 수 있습니다.
- Production systemd installer는 새 root archive를 자동 선택합니다. 1.2.1에서 만든
  manifest/checksum bundle은 기존의 checksum·경로 검증을 유지한 채 계속 지원합니다.

## Compose와 reverse proxy

- `docker-compose.yaml`은 JRE image에서 빌드된 Spring archive를 실행하는 application
  service 하나만 포함합니다.
- Archive와 `public/`은 read-only로 mount하고 application data는 named volume에
  보존합니다. Source build와 custom Dockerfile은 필요하지 않습니다.
- Nginx와 Apache HTTP Server image/service를 Compose에서 제거했습니다.
- 대신 생성 프로젝트의 `deploy/` 아래에 host 설치용 Nginx/Apache HTTP Server 샘플
  설정을 제공합니다. SPA 또는 JSP routing, WebSocket, SSE 설정을 각각 포함하며 이
  샘플은 bundle에 복사하지 않습니다.

## 문서와 검증

- 영문·국문 README, build/deployment 문서, 생성 프로젝트 README·AI 인스트럭션을
  네 항목 bundle 계약과 application-only Compose 사용법에 맞췄습니다.
- Generator, 다섯 템플릿, optional HTTP Helper의 버전을 `1.2.2`로 동기화했습니다.
- Generator Maven test 96개와 문서 정책 검증을 통과했습니다.
- 새 bundle과 1.2.1 legacy bundle의 systemd 설치 경로를 각각 회귀 테스트했습니다.
- 다섯 frontend 템플릿의 fresh create, install, audit, test, build, 최소 bundle 검증을
  통과했고 각 npm audit 결과는 취약점 0건입니다.
- Docker의 Go 1.24 환경에서 optional HTTP Helper의 test와 vet을 통과했으며, Nginx와
  Apache HTTP Server 공식 image로 네 proxy sample의 구문을 검증했습니다.
