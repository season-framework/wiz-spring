# WIZ Spring 0.0.3

릴리즈 날짜: 2026-07-01

WIZ Spring `0.0.3`은 CLI 이름과 배포 단위를 `wiz-spring` 기준으로 정리한 릴리즈입니다. 단일 실행 jar로 project bundle을 포함해 배포하는 흐름을 추가하고, README의 실행 예시를 새 CLI 이름에 맞췄습니다.

## 주요 변경

- CLI command 이름과 help/version 표기를 `wiz-java`에서 `wiz-spring`으로 변경했습니다.
- `project jar` command를 추가해 build된 project bundle을 standalone Spring Boot jar로 패키징할 수 있게 했습니다.
- standalone project jar는 인자 없이 실행하면 내장 project bundle을 사용자 cache에 풀고 server를 시작합니다.
- `create`, `kill`, `project` command의 출력과 예시를 `wiz-spring` 이름 기준으로 정리했습니다.
- README의 빠른 시작, 단일 jar 배포, alias, command coverage 내용을 최신화했습니다.

## 업그레이드 안내

- Runtime artifact는 `target/wiz-spring-0.0.3.jar`입니다.
- 기존 shell alias가 `wiz-java`를 가리키고 있으면 `wiz-spring`으로 교체하세요.
- project 단일 배포가 필요하면 runtime jar에서 `project jar --root ... --project ... --output ...`을 실행합니다.

## 검증

- `./mvnw test`
- `java -jar target/wiz-spring-0.0.3.jar --version`
- `git diff --check`
