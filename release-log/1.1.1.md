# WIZ Spring 1.1.1

상태: released (`1.1.1` 태그, 2026-08-30)

WIZ Spring `1.1.1`은 generator와 다섯 프로젝트 템플릿의 런타임·빌드 도구를
안정적인 최신 세대로 정렬하고 검증 경계를 강화한 유지보수 릴리스입니다.

## 런타임과 빌드 도구

- generator와 생성 프로젝트의 Java 기준을 25로 올렸습니다.
- Spring Boot를 4.1.1로 올리고 BOM 관리 Spring Framework 7.0.9, 관련 Maven plugin과 테스트 구성을 정합화했습니다.
- Angular 템플릿을 22 계열로 올리고 Node.js 24 및 npm 11 도구 체계를 적용했습니다.
- React와 공통 npm 의존성을 갱신하고 다섯 템플릿의 lockfile을 재생성했습니다.

| 항목 | 1.1.1에 고정된 기준 |
| --- | --- |
| Java | release 25, full JDK 25+ |
| Spring | Spring Boot 4.1.1, Spring Framework 7.0.9(Boot BOM 관리), springdoc 3.1.0 |
| Maven | Wrapper 3.9.15 |
| Node.js | `^22.22.3 || ^24.15.0` LTS |
| Angular | runtime 22.1.4, CLI/build 22.1.6, TypeScript 6.0.3 |
| React | React 19.2.8, Vite 8.2.2 |

## 안정성

- production profile에서 OpenAPI와 Swagger UI를 기본 비활성화하고 환경 변수로 명시적으로 활성화할 수 있게 했습니다.
- 템플릿 버전 정책 테스트와 다섯 템플릿 일괄 검증 스크립트를 추가했습니다.
- Docker generator·helper 이미지의 Java와 Node.js 버전을 생성 프로젝트 정책에 맞췄습니다.

## 문서와 AI 인스트럭션

- 루트 README, 생성 프로젝트 README, `AGENTS.md`, Copilot 진입점,
  backend/deployment/frontend AI 계약에 위 버전 표를 동일하게 반영했습니다.
- 0.2.x의 `WizContext`, `api.java`, runtime dispatcher, `wiz-spring build/run`
  계약은 1.1.1 현재 인스트럭션에서 제거했습니다.
- 문서와 템플릿 버전이 다시 어괋나지 않도록 문서 정책 검증을 추가했습니다.
