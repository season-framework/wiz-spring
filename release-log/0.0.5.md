# WIZ Spring 0.0.5

릴리즈 날짜: 2026-07-02

WIZ Spring `0.0.5`는 원본 WIZ CLI와의 사용성 차이를 줄이기 위해 `service`, `run`, `create` 명령을 보강한 릴리즈입니다. systemd 서비스 생성 스크립트, 서비스 목록 출력, 포트 설정 해석을 정리해 개발 모드 실행 흐름을 더 예측 가능하게 만들었습니다.

## 주요 변경

- `wiz-spring service list`를 border가 있는 표 형식으로 출력하도록 개선했습니다.
- 서비스 목록에서 `bundle`, `command` 컬럼을 제거하고, `config` port는 가능한 경우 workspace/project 설정의 실제 `server.port` 값으로 표시합니다.
- `service install/regist`가 생성하는 실행 파일을 `java -jar ... --root ...` 고정 실행 대신 workspace로 `cd`한 뒤 `wiz-spring run`을 호출하는 개발 모드 형식으로 변경했습니다.
- systemd 비대화형 환경에서 `/root/.bashrc`가 조기 반환되어 `wiz-spring` alias를 못 찾는 문제를 줄이기 위해 서비스 스크립트에 `PS1` 설정, alias 확장, 명령 존재 확인을 추가했습니다.
- `service install/register`, `service uninstall/remove/delete/rm/unregister`, `service list/ls` alias와 상세 메타데이터 출력을 보강했습니다.
- `create`와 `run`이 설정 또는 기본 포트가 사용 중이면 사용 가능한 포트를 스캔해 선택하도록 정리했습니다.
- workspace/project `config/application.yml`의 포트 충돌을 줄이기 위해 기본 project 템플릿과 demo 설정에서 active `server.port` 위치를 정리했습니다.
- README의 artifact 경로, service command 설명, 검증 기준을 `0.0.5` 기준으로 갱신했습니다.

## 업그레이드 안내

- Runtime artifact는 `target/wiz-spring-0.0.5.jar`입니다.
- 기존에 설치한 systemd 서비스는 새 스크립트가 자동 반영되지 않습니다. 새 jar로 `wiz-spring service install <name> --root <workspace>`를 다시 실행하세요.
- `service install --jar`는 호환용으로만 허용되며, 생성 스크립트는 기본적으로 `wiz-spring run`을 사용합니다. 다른 실행 파일명이 필요하면 `--command`를 사용하세요.
