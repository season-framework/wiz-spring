# WIZ Spring 0.0.4

릴리즈 날짜: 2026-07-02

WIZ Spring `0.0.4`는 runtime 설정을 프로젝트별로 더 안전하게 조정할 수 있도록 정리하고, project runtime cache와 공급망 추적 산출물을 보강한 릴리즈입니다.

## 주요 변경

- `wiz.socket`, `wiz.redirect`, `wiz.http`, `wiz.api`, `wiz.project` 설정을 Spring properties로 분리했습니다.
- WebSocket과 Socket.IO polling origin 검사를 같은 `wiz.socket.allowed-origins` 기준으로 처리합니다.
- Socket.IO polling session의 idle TTL, 최대 session 수, session별 queue 크기를 설정할 수 있습니다.
- Redirect 정책을 `any`, `local-only`, `allowlist`로 설정할 수 있도록 분리했습니다.
- Project runtime cache를 도입해 bundle marker와 dependency digest가 유지되는 동안 project classloader/runtime을 재사용합니다.
- Runtime cache 폐기 시 project-local JPA context도 함께 닫히도록 sample JPA helper를 정리했습니다.
- `bundle/.wiz-dependencies.json`, `.wiz-build.json` digest, `target/bom.json`, standalone jar checksum 등 공급망 추적 산출물을 보강했습니다.
- README의 runtime config, socket/redirect 정책, 검증 기준, 0.0.4 artifact 경로를 최신화했습니다.

## 업그레이드 안내

- Runtime artifact는 `target/wiz-spring-0.0.4.jar`입니다.
- 기존 개발 호환성을 위해 `wiz.socket.allowed-origins`와 `wiz.redirect.policy` 기본값은 각각 `["*"]`, `any`입니다.
- 운영에서 origin 또는 redirect를 제한하려면 project `config/application.yml`에서 명시적으로 좁히세요.
- 장시간 socket polling 연결이 많은 환경에서는 `polling-session-ttl-millis`, `max-polling-sessions`, `polling-queue-capacity` 값을 workload에 맞게 조정하세요.
