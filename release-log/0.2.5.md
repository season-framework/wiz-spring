# WIZ Spring 0.2.5

릴리즈 날짜: 2026-07-16

WIZ Spring `0.2.5`는 `build --package`를 첫 bundle build 이전으로 제한하던 제약을 제거한 패치 릴리즈입니다. WIZ source가 원본이고 Spring 구조는 build 때 재생성되므로, 기존 build 이력과 관계없이 package root를 변경할 수 있습니다.

## 주요 변경

- `build --package <package>`를 첫 build 전용 옵션이 아니라 언제든 사용할 수 있는 package 설정 변경 옵션으로 정리했습니다.
- package가 달라지면 `wiz.java.package-root`, workspace `pom.xml`의 groupId와 WIZ Java source의 package 참조를 함께 갱신합니다.
- package 변경 build는 자동으로 clean 처리하여 기존 `build/` generated Spring tree와 `bundle/`을 제거한 뒤 새 package 기준으로 재구성합니다.
- 이미 standalone JAR을 만든 workspace는 package 변경 후 `jar` 명령으로 다시 패키징해야 한다는 점을 README와 instruction 문서에 명시했습니다.
- 동일한 package를 다시 지정한 경우에는 package 변경으로 간주하지 않으며, 명시적인 전체 정리가 필요하면 기존처럼 `--clean`을 함께 사용합니다.

## 0.2.4 workspace migration

workspace를 다시 생성하거나 WIZ source를 수동으로 Spring 디렉터리 구조로 옮길 필요가 없습니다. runtime JAR을 `0.2.5`로 교체한 뒤 원하는 package를 지정해 build합니다.

```bash
runtime=/root/workspace/wiz-java/wiz-spring/target/wiz-spring-0.2.5.jar
workspace=/path/to/existing-workspace

java -jar "$runtime" --version
java -jar "$runtime" build --root "$workspace" --package com.example.renamed
```

이 명령은 package가 바뀌면 자동으로 clean build합니다. 변경 후 다음 항목을 확인합니다.

- `config/application.yml`의 `wiz.java.package-root`
- workspace `pom.xml`의 `<groupId>`
- `build/src/main/java/<새 package 경로>/...` 생성 여부
- 이전 package 경로의 generated class가 남아 있지 않은지
- `bundle/.wiz-build.json`의 `javaPackageRoot`

standalone JAR을 사용하는 경우 새 bundle을 포함하도록 다시 생성합니다.

```bash
java -jar "$runtime" jar --root "$workspace" --output /tmp/wiz-app.jar
```

## 호환성 주의사항

- `build/`와 `bundle/`은 generated output이므로 package 변경 시 제거됩니다. 이 디렉터리에 직접 작성한 파일이 있다면 WIZ source나 별도 보관 위치로 먼저 옮깁니다.
- package 문자열과 일치하는 WIZ Java source의 package/import 참조를 갱신하지만, 문자열 literal이나 외부 파일처럼 자동 변경 대상이 아닌 custom 참조는 build 후 확인합니다.
- `0.2.4`의 configuration profile, Git ignore, session cookie와 `wiz.yml` migration은 그대로 유지됩니다.

## 검증

- `./mvnw test`
- `./mvnw -DskipTests clean package`
- `java -jar target/wiz-spring-0.2.5.jar --version`
- packaged JAR로 동일 workspace를 두 번 build하면서 package root 변경
- 새 package generated class 생성, 이전 package generated class 제거, config/pom/build marker 갱신 확인
- `docker build --check --build-context wiz-spring-instruction=../wiz-spring-instruction --target runtime .`
- `git diff --check`
