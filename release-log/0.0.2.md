# WIZ Spring 0.0.2

릴리즈 날짜: 2026-05-05

WIZ Spring `0.0.2`는 Python WIZ `2.5.2` 기반 포팅의 두 번째 릴리즈입니다. 이번 릴리즈의 중심은 CLI 호환성 확대, Java sample project 내장, project-local runtime 경계 정리, 그리고 HTTP(S) 기반 `wiz.socket()` 호환성입니다.

## 주요 변경

- 기본 sample project를 jar 내부 resource로 내장했습니다. `wiz project create`에서 `--uri`/`--path`가 없으면 별도 외부 디렉터리 없이 Java sample project가 생성됩니다.
- `wiz project create`가 기본적으로 clean bundle build까지 수행합니다. 생성만 필요한 경우 `--skip-build`를 사용할 수 있습니다.
- `wiz run` 기본 host는 `0.0.0.0`, 기본 port는 `3000`입니다. workspace/project `config/application.yml`과 CLI option으로 override할 수 있습니다.
- 기존 frontend 패턴에 맞춰 `wiz.socket()`이 `ws://`/`wss://` URL을 직접 쓰지 않고 HTTP(S) namespace로 연결되도록 복원했습니다.
- `socket.java`는 `project build` 이후 다음 dispatch부터 새 handler를 읽습니다. 서버 재시작 없이 socket handler 변경을 반영할 수 있습니다.
- Core jar에서 sample 전용 DB/ORM/auth/session 구현을 분리했습니다. Spring ORM/Hibernate/SQLite/password helper는 sample project source와 sample `pom.xml`에만 포함됩니다.

## Runtime

- Project `pom.xml` dependency는 `wiz project build` 중 Maven `dependency:copy-dependencies`로 해석되며 Java compile/runtime classpath에 포함됩니다.
- Project-local `lib/*.jar`, `target/dependency/*.jar`, bundle `lib/*.jar`를 API, model, controller, route, socket loading에 포함합니다.
- JSON request body를 `wiz.request().query(...)`에서 읽을 수 있도록 기존 WIZ app API 호출 패턴에 맞췄습니다.
- Sample project의 `/auth/check`는 비로그인 상태에서도 HTTP `200`을 반환하고, 인증 상태는 response body에 담습니다.
- Spring core가 `/socket.io/`에서 Socket.IO v4 HTTP long-polling compatibility를 처리합니다.
- Project-local socket handler 결과에서 현재 namespace/room으로 broadcast할 수 있습니다.

## Project Template

- Embedded Java sample project는 `src/main/resources/wiz/templates/default-project-java/` 아래에 압축 해제된 resource로 저장되어 git diff에서 변경 내용을 확인할 수 있습니다.
- `/chat` sample page와 `page.chat/socket.java` lobby chat 예제를 추가했습니다.
- 비로그인 chat 사용자는 socket session id 기준으로 구분됩니다.
- `src/model/AuthService.java`, `src/model/SessionService.java`를 project-local auth/session override 기본 위치로 정리했습니다. 기존 fallback path도 유지합니다.
- Sample DB 설정은 `src/portal/season/model/orm`, password helper는 `src/portal/season/model/security`에 둡니다.
- Sample entity는 작은 nested `Repository` helper를 entity 파일 안에 포함해 필수 파일 분리를 줄였습니다.
- Sample `config/application.yml`에 host/port, auth/session class override, SQLite, MySQL, PostgreSQL, Hibernate dialect, SQL logging 기본값과 커스텀 예시를 주석으로 추가했습니다.
- 비어 있던 legacy template directory를 제거했습니다.
- PWA service worker와 auth route는 core controller가 아니라 sample project route source로 제공합니다.

## Core Boundary

- Core runtime boundary에서 sample-specific SQLite, Spring Security Crypto, portal backend provider, PWA, SMTP, season config model, session model, Python migration/stub concern을 제거했습니다.
- Sample-only `wiz.orm()`을 `WizContext`에서 제거했습니다. Project data access는 `wiz.models()`를 통해 project-local model/helper class로 구현합니다.
- Core의 `PageXyzSocketController` sample 구현을 제거했습니다. Socket controller는 project `socket.java` source에서 생성됩니다.

## 업그레이드 안내

- Runtime artifact는 `target/wiz-spring-0.0.2.jar`입니다.
- 기존 project는 legacy auth/session 위치를 계속 사용할 수 있지만, 새 project는 `src/model/AuthService.java`, `src/model/SessionService.java` 사용을 권장합니다.
- MySQL 또는 PostgreSQL을 사용할 때는 project `pom.xml`에 JDBC driver dependency를 추가하고, project `config/application.yml`의 `sample.datasource.*`, `sample.jpa.dialect`를 수정하세요.
- Project별 Java dependency는 WIZ Spring core `pom.xml`이 아니라 `project/<name>/pom.xml`에 둡니다.
