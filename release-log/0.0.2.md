# WIZ Spring 0.0.2

Release date: 2026-05-06

WIZ Spring `0.0.2`는 Python WIZ `2.5.2` 기반 포팅의 두 번째 릴리즈입니다. 이번 릴리즈의 중심은 CLI 호환성 확대, Java sample project 내장, project-local runtime 경계 정리, 그리고 HTTP(S) 기반 `wiz.socket()` 호환성입니다.

## Highlights

- 기본 sample project를 jar 내부 resource로 내장했습니다. `wiz project create`에서 `--uri`/`--path`가 없으면 별도 외부 디렉터리 없이 Java sample project가 생성됩니다.
- `wiz project create`가 기본적으로 clean bundle build까지 수행합니다. 생성만 필요한 경우 `--skip-build`를 사용할 수 있습니다.
- `wiz run` 기본 host는 `0.0.0.0`, 기본 port는 `3000`입니다. workspace/project `config/application.yml`과 CLI option으로 override할 수 있습니다.
- 기존 frontend 패턴에 맞춰 `wiz.socket()`이 `ws://`/`wss://` URL을 직접 쓰지 않고 HTTP(S) namespace로 연결되도록 복원했습니다.
- `socket.java`는 `project build` 이후 다음 dispatch부터 새 handler를 읽습니다. 서버 재시작 없이 socket handler 변경을 반영할 수 있습니다.
- Core jar에서 sample 전용 DB/ORM/auth/session 구현을 분리했습니다. Spring ORM/Hibernate/SQLite/password helper는 sample project source와 sample `pom.xml`에만 포함됩니다.

## CLI

- Added: `wiz bundle`
- Added: `wiz kill --dry-run`
- Added: `wiz service list/regist/unregist/status/start/stop/restart`
- Added: `wiz project app list/create/delete`
- Added: `wiz project controller list/create/delete`
- Added: `wiz project route list/create/delete`
- Added: `wiz project package list/create/delete`
- Added: `wiz project npm list/install/uninstall`
- Updated: `wiz run` now accepts compatibility options `--bundle` and `--log`
- Updated: `wiz project build` prints Java version, npm install logs, Pug/Angular build logs, phase durations, and total build time

## Runtime

- Project `pom.xml` dependencies are resolved during `wiz project build` with Maven `dependency:copy-dependencies` and included in Java compile/runtime classpaths.
- Project-local `lib/*.jar`, `target/dependency/*.jar`, and bundle `lib/*.jar` are included for API, model, controller, route, and socket loading.
- JSON request bodies are available through `wiz.request().query(...)`, matching existing WIZ request behavior for common app API calls.
- `/auth/check` in the sample project returns HTTP `200` even when unauthenticated, with auth status represented in the response body.
- Socket.IO v4 HTTP long-polling compatibility is handled by the Spring core at `/socket.io/`.
- Socket broadcast can target the current namespace/room through project-local socket handler results.

## Project Template

- Embedded Java sample project is stored as unpacked resources under `src/main/resources/wiz/templates/default-project-java/`, so changes are visible in git diff.
- Added `/chat` sample page with `page.chat/socket.java` lobby chat.
- Unauthenticated chat users are distinguished by socket session id.
- `src/model/AuthService.java` and `src/model/SessionService.java` are the preferred project-local auth/session override locations. Legacy fallback paths are still supported.
- Sample DB setup lives under `src/portal/season/model/orm`; password helper lives under `src/portal/season/model/security`.
- Sample entities keep small nested `Repository` helpers in the entity file to reduce required file splitting.
- Sample `config/application.yml` documents default values and customization points for host/port, auth/session class override, SQLite, MySQL, PostgreSQL, Hibernate dialect, and SQL logging.
- Empty legacy template directories were removed.
- PWA service worker and auth routes are sample project route sources, not core controllers.

## Core Boundary

- Removed sample-specific SQLite, Spring Security Crypto, portal backend provider, PWA, SMTP, season config model, session model, and Python migration/stub concerns from the core runtime boundary.
- Removed sample-only `wiz.orm()` from `WizContext`; project data access should be implemented with project-local model/helper classes through `wiz.models()`.
- Removed core `PageXyzSocketController` sample implementation. Socket controllers are generated from project `socket.java` sources.

## Upgrade Notes

- The runtime artifact is now `target/wiz-spring-0.0.2.jar`.
- Existing projects can keep legacy auth/session locations, but new projects should use `src/model/AuthService.java` and `src/model/SessionService.java`.
- For MySQL or PostgreSQL, uncomment/add the matching JDBC driver dependency in the project `pom.xml`, then update project `config/application.yml` under `sample.datasource.*` and `sample.jpa.dialect`.
- Generated projects should keep project-specific Java dependencies in `project/<name>/pom.xml`, not in the WIZ Spring core `pom.xml`.
