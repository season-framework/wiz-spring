# WIZ Spring 0.2.9

상태: released (`0.2.9` 태그, 2026-08-26)

WIZ Spring `0.2.9`는 `create --uri`로 기존 Git 저장소를 가져올 때 인증 상호작용과 Java package root 이전을 안정화하고, Docker 개발 이미지의 Java 환경 검증을 강화한 패치 릴리즈입니다.

## 주요 변경

- `git clone`이 현재 터미널의 표준 입출력을 상속하고 Git terminal prompt를 허용해 private repository의 username, password/PAT, SSH 확인 과정에 응답할 수 있습니다.
- HTTP(S) URI에 username/password를 직접 포함하는 방식은 로그와 process 정보 노출을 막기 위해 거부하고 Git prompt 또는 credential helper 사용을 안내합니다.
- `--path`와 `--uri`로 가져온 source의 기존 package root를 workspace 설정과 Java `package`/`import` 선언에서 추론합니다.
- 추론한 package root를 `--package` 값으로 변경하면서 Java 선언과 import, `pom.xml`, WIZ 설정, handler metadata의 fully qualified class name을 함께 정규화합니다.
- license/header 주석 뒤에 명시적으로 작성된 `package` 선언도 생성 위치에 맞는 package로 교체해 디렉터리 구조와 선언이 어긋나지 않게 합니다.
- Docker runtime과 bind 이미지에서 일반 shell과 login shell 모두 동일한 Java 21 환경을 사용하도록 `JAVA_HOME`과 `PATH`를 명시하고 이미지 검증 script를 추가했습니다.
- Docker context와 Maven resource 처리에서 Angular `node_modules` 및 `.angular` cache를 제외합니다.

## 사용 방법

공개 또는 private Git 저장소의 기존 WIZ source를 새 package root로 가져올 수 있습니다.

```bash
wiz-spring create ./workspace \
  --uri https://git.example.com/team/project.git \
  --package kr.co.example.project
```

Git이 인증을 요구하면 터미널에 표시되는 username/password 또는 SSH prompt에 응답합니다. 자격증명을 URI에 넣지 마세요.
