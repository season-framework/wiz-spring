# WIZ Spring 0.2.8

상태: released (`0.2.8` 태그, 2026-07-29)

WIZ Spring `0.2.8`은 Docker 개발 이미지의 SSH 접속을 root 비밀번호 인증 전용으로 정리하고 Angular 개발 의존성 취약점을 보강한 패치 릴리즈입니다.

## 주요 변경

- SSH 서버에서 root 로그인을 허용하고 비밀번호 인증을 활성화했습니다.
- 공개키 인증을 비활성화하고 인증 방식을 password로 고정했습니다.
- `SSH_PUBLIC_KEY`와 `authorized_keys` 생성·주입 경로를 제거했습니다.
- 컨테이너 시작 시 `SSH_PASSWORD`가 지정되면 root 비밀번호를 설정한 뒤 환경에서 제거합니다. 콜론이나 줄바꿈이 포함된 값은 시작 전에 거부합니다.
- `run.sh`와 `run-bind.sh`가 `SSH_PASSWORD`를 컨테이너에 전달하고 실제 SSH 접속 명령을 출력합니다.
- runtime과 bind 이미지 모두 컨테이너별 SSH host key를 사용합니다.
- Angular 개발 의존성의 `@modelcontextprotocol/sdk`, `@hono/node-server`, `hono`, `brace-expansion`을 취약점이 해결된 버전으로 고정했습니다.

## 사용 방법

이미지에는 기본 root 비밀번호가 없습니다. 컨테이너를 처음 실행할 때 비밀번호를 지정합니다.

```bash
SSH_PASSWORD='change-me' ./run.sh
ssh root@127.0.0.1 -p 2223
```

workspace를 host에 유지하는 bind 이미지도 같은 방식으로 실행합니다.

```bash
SSH_PASSWORD='change-me' ./run-bind.sh
```

SSH가 필요하지 않으면 `WIZ_ENABLE_SSH=false`로 비활성화할 수 있습니다.

## 검증

- Maven 전체 테스트 `278`개와 패키징을 통과하고 `wiz-spring 0.2.8` 버전 출력을 확인했습니다.

- Docker 이미지의 runtime health check와 bind workspace 초기화를 확인했습니다.
- Angular 템플릿에서 `npm audit` 취약점이 `0`건인지 확인했습니다.
