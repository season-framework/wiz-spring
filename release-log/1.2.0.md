# WIZ Spring 1.2.0

상태: released (`1.2.0` 태그, 2026-09-09)

WIZ Spring `1.2.0`은 생성 프로젝트의 개발·서비스·설정·배포 lifecycle을 프로젝트
자체가 완전히 소유하도록 정리한 릴리스입니다. WIZ Spring CLI는 생성과 설치를 돕지만,
설치된 애플리케이션의 build 또는 runtime에는 참여하지 않습니다.

## 실시간 개발과 서비스

- `npm run dev`가 Spring 애플리케이션, 백엔드 compile watcher, 프론트엔드 watcher를
  하나의 lifecycle로 실행합니다.
- 백엔드는 compile 성공 후에만 Spring DevTools trigger를 갱신합니다. 실패한 수정은
  마지막 정상 애플리케이션을 내리지 않으며, 다시 성공하면 프로세스를 수동 재시작하지
  않아도 반영됩니다.
- 모든 프론트엔드 watcher가 Spring이 제공하는 정적 산출물에 성공한 build를 기록하므로
  브라우저 새로고침으로 결과를 확인할 수 있습니다.
- `service install`의 기본값을 생성 프로젝트의 `npm run dev`를 실행하는 개발 모드로
  정했습니다. Immutable bundle 서비스는 `--production` 또는 `--bundle`로 명시합니다.
- 설치된 launcher에는 확인된 `npm` 또는 `java` 절대 경로와 프로젝트 명령만 기록합니다.
  실행 중인 서비스는 WIZ Spring executable이나 generator JAR를 호출하지 않습니다.

## 환경 설정

- 다섯 템플릿과 optional HTTP Helper 모두 실행 가능한 기본값이 든 `.env`를 바로
  제공합니다. `.env.example`을 복사하는 단계는 없습니다.
- npm script와 기본 개발 서비스는 프로젝트 `.env`를, bundle launcher와 production
  서비스는 bundle `.env`를 읽습니다.
- 이미 export된 환경 변수는 `.env`보다 우선하고, service의 `--port`와 `--profiles`는
  해당 환경 변수보다 우선합니다. 별도 파일은 `--env-file`로 지정합니다.
- Secret은 기본 `.env`에 두지 않고 process 환경 또는 외부 환경 파일로 주입하도록
  문서와 AI 인스트럭션을 통일했습니다.

## 독립 배포 번들

- `npm run bundle`이 애플리케이션 archive, 정적 파일, proxy/Compose 설정, `.env`,
  `run.sh`, manifest, checksum과 runtime `data/` 경계를 함께 생성합니다.
- 생성된 `bundle/`만 복사한 뒤 JDK 25 이상과 POSIX shell만 있는 서버에서
  `./run.sh`로 실행할 수 있습니다. Node.js, npm, Maven, WIZ Spring은 필요하지 않습니다.
- Checksum은 immutable 파일을 검증하고 `.env`와 `data/`만 명시적인 runtime 변경
  영역으로 둡니다.

## CLI와 인스트럭션

- 사용하지 않는 `completion` 명령과 구현·테스트를 제거했습니다.
- Angular 계열 lockfile의 `qs`를 `6.16.0`으로 갱신하고 다섯 템플릿의 `npm audit`을
  다시 통과했습니다.
- 생성되는 `AGENTS.md`, Copilot 진입점, backend/frontend/deployment 문서를 watcher 성공,
  build 검증, `.env`, 서비스 모드, runtime 독립성 계약에 맞췄습니다.
- 독립 `wiz-spring-instruction` 저장소도 같은 1.2.0 계약으로 갱신했습니다.

## 검증

- Generator Maven test 94개와 문서 정책 검증 통과
- Helper Go format/vet/test와 Docker Compose 구성 검증 통과
- 다섯 템플릿 fresh create 후 설치, 보안 감사, backend/frontend test, build, bundle 및
  checksum 검증 통과
- 실제 systemd 개발 서비스에서 백엔드와 화면 수정의 실시간 반영 확인
- WIZ Spring, Node.js, npm, Maven이 없는 JDK-only 실행 환경에서 독립 bundle 기동 확인
